# Проверка ценовых уведомлений

Функция проверяет валютные цели только для текущего авторизованного пользователя, поэтому не требует `service_role`. Она использует те же VAPID Secrets, что и `push-notify`.

```bash
supabase functions deploy check-price-alerts
```

Клиент вызывает проверку при открытии главной страницы и затем раз в 15 минут. Уведомление отправляется на все подписанные устройства пользователя; повтор одной цели ограничен интервалом в 6 часов.
